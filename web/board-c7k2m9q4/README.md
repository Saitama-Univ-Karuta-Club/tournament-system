# Admin Page

This directory contains the first admin page for managing:

- tournaments
- members

Published path note:

- the public directory name is intentionally non-obvious: `board-c7k2m9q4/`
- do not copy the production URL into public docs or repository notes

## Current Behavior

- first branches by `大会` or `メンバー`
- each branch can switch between `新規入力` and `登録済み一覧`
- creates and updates tournaments from the browser
- creates and updates members from the browser
