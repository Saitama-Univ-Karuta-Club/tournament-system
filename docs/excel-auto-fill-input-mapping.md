# Excel 申込名簿の入力位置マッピング

解析日: 2026-10-23

## 結果

`excel-auto-fill-samples/originals` にある24ファイルを、16種類のレイアウトとしてマッピングした。原本は変更していない。

実装で使用するセル位置、入力元、値の変換、保持すべき数式・記入例、手動確認項目は [`excel-auto-fill-input-mappings.json`](./excel-auto-fill-input-mappings.json) に記録している。

| 状態 | 件数 | 内容 |
|---|---:|---|
| `.xlsx` 入力位置確定 | 23 | 15種類のレイアウト。級別複数シート、2ページ構成、100名枠、保護シートを含む |
| `.xls` 入力位置確定 | 1 | 足利大会。Google Driveで一時的に `.xlsx` へ変換してから入力する |

## 自動入力できる項目

- 会名、都道府県、申込責任者、電話番号、メールアドレス、振込名義人
- 選手の姓・名、姓よみ・名よみ、出場級、段位
- 申込開始日時点の出場回数
- テンプレートで要求される場合の所属会・学校名

氏名・よみがなは、テンプレートごとに「姓と名を別セル」「全角スペースで結合」「半角スペースで結合」「空白なし」を切り替える。

## 自動入力せず確認する項目

- 大会固有の抽選優先条件、過去入賞歴、希望日
- 地域制限に関係する在住・在学・在勤情報
- 全日本かるた協会会員番号、学年、臨時バス人数
- 自動入力欄数を超える申込者

これらは空欄のまま担当者へ確認を促す。推測値は入力しない。

## 実装時の安全条件

1. シート名と複数の見出しセルが一致したときだけレイアウトを確定する。
2. 未知のレイアウトには書き込まない。
3. 数式セル、連番列、記入例、編集不可シートを上書きしない。
4. 結合セルは左上セルだけを書き換える。
5. 入力枠を超えた場合はファイルを生成せず、担当者へ手動対応を求める。
6. 生成後に、氏名・級・人数・数式残存を機械検証してから保存する。

## 実装済みの生成フロー

1. サークル内締切を過ぎたExcel提出大会を定期処理が検出する。
2. R2に保存した申込名簿原本を読み込み、`.xls` だけはバックアップWorker経由で一時的に `.xlsx` へ変換する。
3. シート名・見出しセル・元ファイル名からレイアウトを特定する。
4. 参加希望者、登録情報、年度内出場回数をD1から取得して入力する。
5. 氏名、級、人数、数式の保持を検証した後、生成版をR2へ保存する。
6. 大会の申込名簿リンクを生成版へ差し替える。元ファイルは削除せず、再生成時の原本として保持する。

管理画面のTODOから「名簿を自動入力／再生成」を押して、締切前を含め任意の時点で手動生成することもできる。

## 対応状況

- `.xlsx` の実サンプル23ファイル・15レイアウトで生成を確認済み
- `.xls` 1レイアウトは変換後のセル位置まで対応済み
- 未知の形式、入力上限超過、数式セルへの書き込み、危険な結合セルを検出した場合は原本を変更せず中止
- 大会固有の手動項目や未設定の連絡先がある場合は、生成結果に確認事項として表示

新しい形式が届いた場合は、原本を `excel-auto-fill-samples/originals` に保存し、
[`excel-auto-fill-input-mappings.json`](./excel-auto-fill-input-mappings.json) にレイアウト定義を追加してから実ファイル検証を行う。
